Research

Interpretability and AI safety

Machine learning models, and language models in particular, are used more and more in settings where their mistakes matter. We study how these models work internally: which parts of a model produce a given behaviour, and how fine-tuning changes them. We also study the evaluations used to judge whether a model is safe, such as safety tests, audits and defences against harmful fine-tuning, and ask when their results can be relied on. Some of these questions are philosophical as well as technical.

Data discovery and environmental monitoring

Much of the data that science and public bodies rely on comes as tables, knowledge graphs and measurements taken over time. Before such data can be used, someone has to find it, and its description has to match what is in it. We build search methods that find datasets by what they contain, test whether descriptions written by language models help people find data or mislead them, and study retrieval over knowledge graphs that keeps track of where an answer came from. We also apply machine learning to environmental monitoring. We compare plankton communities in the western Baltic and forecast how they change, map shallow flooding on farmland from satellite radar images, and process Earth observation data with Danish public organisations.

Software engineering

Language models and coding agents now write and change real software, and machine learning has become a part of many software systems. We study both sides of this. On one side we ask what language models know about software architecture, and how coding agents shape the structure of the systems they help build. On the other we design software with machine learning inside it, from pipelines that tune and evaluate models to architectures for search and retrieval.
