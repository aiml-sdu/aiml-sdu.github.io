Research

Interpretability and AI safety

How machine learning models work internally, and whether the evaluations used to call them safe can be relied on. Most of the work is on language models: which parts of a model produce a behaviour, how training changes them, and what safety tests and audits measure. Some of the questions are as much philosophical as technical.

Mechanistic interpretability · AI safety · Evaluation · Philosophy of machine learning

Data discovery and environmental monitoring

Finding data and learning from it. We work on search methods for tables and datasets, on metadata written by language models, and on retrieval over knowledge graphs. We also use machine learning to monitor the environment, from plankton communities in the western Baltic to flooded farmland seen by satellite.

Dataset search · Knowledge graphs · Retrieval · Environmental monitoring

Software engineering

Language models and coding agents now take part in building software, and machine learning has become a part of many software systems. We study what language models know about software architecture, how coding agents shape the systems they help build, and how to design software with machine learning inside it.

Software architecture · Coding agents · Language model evaluation · Machine learning pipelines
