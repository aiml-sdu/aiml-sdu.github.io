Research

Software engineering and machine learning

Language models now answer questions about how software should be built, and coding agents choose frameworks, set up infrastructure and connect services, often in seconds. These are decisions about a system’s architecture, yet few people review them as such. We study what language models know about software architecture, and how coding agents shape the structure of the systems they help build.

The other side of the work is software with machine learning inside it. We design pipelines that tune and compare models, and architectures for retrieval systems in which a language model plans and checks its own searches, built so that each step can be inspected.

Themes
  • Architecture knowledgeWhat language models know about cloud software architecture, and how the form of a test changes what it measures.
  • Coding agentsThe architectural choices that agents writing code make without anyone reviewing them, and how to bring those choices under review.
  • Systems with machine learning insidePipelines that tune and evaluate models, and retrieval systems built around language model agents whose steps can be audited.
